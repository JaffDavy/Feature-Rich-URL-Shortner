
LinkVault - URL Shortener
LinkVault is a modern URL shortening service that allows users to create short, memorable links that redirect to longer destination URLs. With features like custom short codes, link analytics, and user authentication, LinkVault offers a comprehensive solution for managing and tracking your shortened links.

Features
URL Shortening: Convert long URLs into short, easy-to-share links
Custom Short Codes: Create personalized short codes for your links
Link Analytics: Track clicks and performance of your shortened URLs
User Authentication: Secure registration and login system
User Dashboard: Manage all your shortened links in one place
Link Expiration: Set expiration dates for your short links
Technologies Used
Frontend: React, TypeScript, Tailwind CSS, shadcn/ui
State Management: React Context API, TanStack Query
Routing: React Router
UI Components: Modern, responsive design with shadcn/ui components
Getting Started
Prerequisites
Node.js (v18 or later)
npm or bun
Installation
Clone the repository

git clone <repository-url>
cd linkvault
Install dependencies

npm install
Start the development server

npm run dev
Open your browser and navigate to http://localhost:5173

Usage
Creating a Short URL
Navigate to the home page
Enter the long URL you want to shorten
Optionally, enter a custom code for your short URL
Click "Create Short Link"
Copy and share your new shortened URL
Managing Your Links
Sign up for an account or log in
Access your dashboard to view all your shortened links
Track analytics for each link
Edit or delete your links as needed
